# Roadmap

P0 implementado localmente: SSR/Auth, RLS, favoritos, painel, calendário, clube/classificação, sem spoiler, perfil, solicitação de exclusão, PWA segura, adaptador/job e qualidade automatizada. Ver checklist para evidências e gates externos; não equivale a produção aprovada.

Gates de P0: validar Auth/SMTP remoto, API e licenças reais por temporada, agendamento, edge/HTTPS/cache, backups, canal de contato e revisão jurídica. Completar teste de duas sessões persistidas em Supabase staging, recuperação e atendimento de exclusão.

P1: elencos/transferências confirmadas somente com cobertura e licença consistentes; mais ligas pelo mesmo adaptador; melhorar paginação de dados esportivos se volume exigir; automação de exclusão com infraestrutura revisada.

Pós-MVP sujeito a nova decisão de produto: MFA via provedor, observabilidade gerenciada e experiência de instalação ampliada. Não implementados: live alta frequência, chat, rede social, IA, pagamentos, anúncios, notícias, uploads, push, scraping ou apostas.
